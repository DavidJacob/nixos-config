# nixos-config

NixOS, Home Manager and dotfiles for David's three laptops, in one flake.
The repo lives at `~/nixos-config` on every machine.

| Name      | Machine                               | Use      |
| --------- | ------------------------------------- | -------- |
| `maple`   | Acer Swift 3 (SF314-59)               | personal |
| `macbook` | MacBook Pro 13" 2017 (MacBookPro14,2) | personal |
| `work`    | ThinkPad T14 Gen 7                    | Famedly  |

## Layout

```
flake.nix                 inputs, and the three machines
modules/
  common.nix              system settings every laptop shares
  disk-layout.nix         LUKS + LVM disk layout for disko (macbook, work)
hosts/<name>/
  default.nix             that machine's hardware, disk and extras
  hardware-configuration.nix   generated by nixos-generate-config
home/
  common.nix              home folder settings every laptop shares
  zsh.nix noctalia.nix neovim.nix cheatsheet.nix
  hosts/<name>.nix        per machine: git email, GPG key, stateVersion
hypr/
  hyprland.lua            Hyprland, shared
  hosts/<name>.lua        that laptop's own screen (scale, position)
nvim/                     LazyVim config
```

`hypr/` and `nvim/` are linked into `~/.config` as writable links, so edits
there apply without a rebuild.

## Everyday commands

```sh
rebuild          # apply changes (builds the config named after this machine's hostname)
update           # update all inputs, then rebuild
clean            # delete old generations
```

Building a specific machine, e.g. to check the MacBook's config from maple:

```sh
nixos-rebuild build --flake ~/nixos-config#macbook
```

## Secrets

Nothing secret is committed. Per-machine secrets are added by hand after
installation (see INSTALL.md), e.g. the Fleet enrollment key on `work`.
